## MODIFIED Requirements

### Requirement: Foreground server startup
The built image SHALL start the installed Linux dedicated-server startup script through an entrypoint generated by the Dockerfile, without requiring a separate repository startup script, and SHALL keep the container running while the game server process is running. When no managed administrator password is configured, the entrypoint SHALL replace itself with the server process. When it supervises prompt-aware administrator initialization, it SHALL forward normal container termination to the server process group.

#### Scenario: Start a newly built image
- **WHEN** an operator starts a container without overriding its command
- **THEN** the Project Zomboid server startup process runs in the container foreground through the Dockerfile-generated entrypoint
